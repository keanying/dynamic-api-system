插件库

可复用的 Python 函数集，供 API 插件引用

插件库使用教程

1. 插件库是什么
插件库是一段可复用的 Python 代码，里面定义若干工具函数。多个 API 插件可以共享同一个库，避免重复写相同逻辑。

2. 新建一个库（仅超级管理员）
点「新建插件库」，填写库名（英文标识，如 utils），在代码区定义函数，例如：

def format_money(cents):
    return round(cents / 100, 2)

def add_label(rows, prefix):
    for r in rows:
        r["label"] = prefix + str(r.get("id", ""))
    return rows

3. 在 API 插件里引用
在插件 API 的代码开头用注释声明引用，多个库用逗号分隔：

# require: utils
def main(params, ctx):
    rows = ctx.query("my_db", "SELECT id FROM t")
    rows = add_label(rows, "U-")          # 直接调用库里的函数
    return {"money": format_money(12345), "rows": rows}

声明 # require: utils 后，库里定义的 format_money、add_label 等函数就能在 main 里直接调用，就像它们写在同一个文件里一样。

4. 注意事项
· 库名只能是字母/数字/下划线，不以数字开头
· 引用多个库：# require: utils, http_helper
· 被禁用或不存在的库会导致 API 执行报错
· ⚠ 插件库代码与插件一样会在服务器执行任意 Python，仅限可信成员维护
